# ❤️ 7 шагов навстречу — романтический квест для Алины

Мобильный сайт для GitHub Pages. Семь романтических глав в парке 30-летия Победы (Краснодар), обязательные фотографии, письма после отправки, финал на Мосту поцелуев.

## Что умеет

- Красивый мобильный интерфейс и скрытые до нужного момента задания.
- Семь заданий и семь личных романтических посланий.
- Кнопка «Выбрать фото» (камера / галерея), предпросмотр, сжатие больших фотографий.
- Отправка **фотографий во вложении** на **artemcepko69@gmail.com** с помощью [FormSubmit](https://formsubmit.co/documentation).
- Возврат на нужный этап после отправки письма через параметр `_next`.
- Сохранение прогресса в localStorage на том же устройстве и в том же браузере. Фото не сохраняются на сайте или GitHub.
- Режим проверки интерфейса `?demo=1` без отправки писем и фотографий.
- Никакого PHP, сервера, платного хостинга или Gmail-пароля.

## 1. Как выложить на GitHub Pages

1. Создайте **публичный** репозиторий на GitHub (например, `7-shagov`).
2. Разархивируйте `7-shagov-k-tebe.zip` на компьютере.
3. Через **Add file → Upload files** загрузите **содержимое папки**, чтобы `index.html`, `app.js`, `styles.css`, `config.js`, `setup.html` находились **в корне репозитория**, а не внутри дополнительной папки.
4. Откройте **Settings → Pages → Build and deployment**. В поле Source выберите **Deploy from a branch**, Branch: `main`, Folder: `/ (root)` и сохраните.
5. Откройте выданный GitHub Pages адрес, обычно `https://ВАШ-ЛОГИН.github.io/7-shagov/`.

## 2. ОБЯЗАТЕЛЬНО: активировать письма до свидания

Отправка работает через FormSubmit.co. **Первая отправка на новый адрес запускает активацию, но не доставляет фото как обычное письмо!**

1. После публикации откройте `https://ВАШ-ЛОГИН.github.io/7-shagov/setup.html`.
2. Нажмите **«Отправить тестовое письмо»** (сначала без фотографии).
3. Откройте `artemcepko69@gmail.com` и найдите письмо от FormSubmit с предложением **активировать форму**. Проверьте «Спам».
4. Перейдите по ссылке активации.
5. **Вернитесь на `setup.html` и отправьте тест ещё раз, теперь приложив небольшую фотографию JPG/PNG.** Убедитесь, что письмо пришло с **самой фотографией во вложении**, а не только с её названием.
6. После проверки можно удалить `setup.html` из публичного репозитория (необязательно, но рекомендуется).

⚠️ Пока вы не проверили вторую отправку **со снимком**, не отправляйте ссылку Алине. В браузере из этой среды отправка настоящего письма не тестировалась, поэтому гарантия доставки возможна только после вашего теста.

## 3. Как проверить все 7 глав без писем

Откройте сайт с `?demo=1`:

`https://ВАШ-ЛОГИН.github.io/7-shagov/?demo=1`

В демо-режиме отдельный прогресс, нет настоящей загрузки фотографии и ничего не отправляется. Вы сможете проверить все семь текстов и финал.

После проверки отправьте Алине обычный адрес **без `?demo=1`**.

## 4. Как работает реальная отправка

- Алина выбирает снимок и нажимает «Отправить фото и открыть письмо».
- Браузер делает обычную форму `POST` `multipart/form-data` на сервис **FormSubmit.co**. По его документации именно эта отправка поддерживает вложения; предел — 10 МБ на всю форму. Сайт предварительно пытается уменьшать большие фото и ограничивает размер снимка 9 МБ.
- В письмо добавляется номер главы, её название и время по Москве.
- Сервис возвращает браузер по полю `_next` на сайт. Только после такого возврата с выданным ссылкой адресом сайт открывает признание и следующий этап.
- При ошибке или отсутствии возврата прогресс не перескакивает вперёд. Можно повторить отправку.

Важно: **возврат с сайта FormSubmit означает, что отправка была обработана сервисом, но не является независимым подтверждением появления письма в Gmail**. Доставка зависит от FormSubmit и почтового сервиса. В первую очередь сделайте пробную отправку и проверяйте «Спам».

## 5. Где сменить адрес отправки

В `config.js`:

```js
window.QUEST_CONFIG = Object.freeze({
  recipient: 'artemcepko69@gmail.com',
  disableCaptcha: true,
  title: '7 шагов навстречу'
});
```

Если хотите скрыть адрес от исходного кода публичного сайта, после подтверждения FormSubmit может выдать случайный идентификатор в качестве *invisible email* (описано в их документации). Тогда потребуется заменить `recipient` на этот идентификатор и проверить работу. **Никогда не добавляйте сюда пароль Gmail, ключи от почты или приватные токены.**

## 6. Приватность и ограничения

- Репозиторий GitHub Pages публичный. Квест **не имеет настоящей авторизации**; любой, кто знает ссылку, может его открыть. Секрет финала скрыт интерфейсом по этапам, но содержимое `app.js` открыто технически любому посетителю.
- Используется `noindex` для поисковиков, но это **не гарантия приватности**.
- Фото пересылаются через сторонний сервис FormSubmit. GitHub и код сайта снимки не хранят; FormSubmit обрабатывает их согласно своим правилам. Не нужно отправлять документы или чувствительные изображения.
- Прогресс привязан к конкретному браузеру и устройству. При очистке localStorage или открытии на другом телефоне начнётся заново.
- Привязка к геопозиции не проверяется: фото считаются подтверждением по правилам игры. На этапе с белочкой есть запасной вариант, если животных не видно.
- Сайт **не блокирует начало до 15:00**. Указанные часы — рекомендованный план, без жёсткого таймера.
- Официальный маршрут длиной около 1,5 км по парку включает Мост поцелуев. Но конкретные места скамеек и белок могут отличаться; ориентируйтесь по дорожкам и не заходите в закрытые участки.

## 7. Если что-то не работает

- **Активация:** загляните в «Спам», повторите первую отправку с `setup.html` и нажмите ссылку из письма.
- **Нет вложения:** убедитесь, что после активации вы отправляли фото через стандартную форму, и проверьте, что размер меньше 9 МБ.
- **Страница не возвращается:** проверьте, что сайт открыт по опубликованному `https://...github.io/...` адресу (а не через `file:///`).
- **Фотография не загружается:** попробуйте JPEG, фото меньше 9 МБ или скриншот.
- **Долго нет письма:** проверьте «Спам» Gmail и работоспособность FormSubmit, прежде чем повторять отправку. Не считайте загрузку успешной, пока не проверили письмо.
